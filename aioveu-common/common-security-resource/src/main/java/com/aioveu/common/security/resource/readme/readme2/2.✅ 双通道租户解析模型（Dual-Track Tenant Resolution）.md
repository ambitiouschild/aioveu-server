## 二、用一张「决策树」把逻辑钉死

```
请求进入
 │
 ├── 有 Authorization: Bearer xxx ?
 │     └── ✅ 是
 │           ↓
 │         JWT 解码
 │           ↓
 │         JWT 版本 / 黑名单校验
 │           ↓
 │         TenantFilter（从 JWT 取 tenantId）
 │           ↓
 │         Controller
 │
 └── 无 JWT ?
       └── ✅ 是
             ↓

             ↓
         ✅ 白名单校验
             ↓
         clientId → tenantId
             ↓
         TenantContextHolder
             ↓
         Controller
```

✅ **两条路，永远不会互相救场**
