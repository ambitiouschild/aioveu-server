## 三、问题点逐个拆解（非常关键）

### ❌ 问题 1：`HIGHEST_PRECEDENCE + 10`是个“伪靠前”

```
Ordered.HIGHEST_PRECEDENCE = Integer.MIN_VALUE
```

所以：

```
HIGHEST_PRECEDENCE + 10 ≈ -2147483637
```

而你的：

```
PUBLIC_TENANT_FILTER = -210
```

👉 **差了 20 亿个数量级**

✅ Spring 能跑

❌ **人类维护不了**

❌ **跨模块无法对齐**

------

### ❌ 问题 2：JWT / Tenant 顺序“看起来晚，实际太晚”

Spring Security 原生 Filter 大致顺序：

| Filter                               | Order |
| ------------------------------------ | ----- |
| SecurityContextPersistenceFilter     | -110  |
| UsernamePasswordAuthenticationFilter | -50   |
| AnonymousAuthenticationFilter        | 0     |
| ExceptionTranslationFilter           | 100   |
| FilterSecurityInterceptor            | 200   |

而你：

```
JWT_VERSION_FILTER = 100;
JWT_BLACKLIST_FILTER = 200;
TENANT_FILTER = 300;
```

👉 **TenantFilter 实际在 Security 授权之后执行**

这会导致：

- 

  ❌ 授权阶段拿不到 tenantId

- 

  ❌ 方法级权限 (`@PreAuthorize`) 看不到租户

- 

  ❌ 你现在这个异常只是冰山一角

------

### ❌ 问题 3：两套 Order 定义 = 架构分裂

你现在的现实是：

| 场景          | 用哪套 Order           |
| ------------- | ---------------------- |
| ClientId 解析 | `TenantFilterOrders`   |
| JWT / Tenant  | `SecurityFilterOrders` |

👉 **没人能保证它们不冲突**

👉 **也没人记得谁在前**

## 四、✅ 正确的设计原则（记住这条）

> **租户解析 = 一条管道，不是两个世界**

```
ClientId（无 JWT）
   ↓
JWT 解码
   ↓
JWT 校验（黑名单 / 版本）
   ↓
TenantFilter（JWT tenantId）
   ↓
Security 授权
   ↓
MVC / MyBatis
```

**Order 必须连续、可预测、可审查**

## 五、✅ 强烈推荐的「唯一正确方案」

### ✅ 合并为一个文件（这是必须的）

```
package com.aioveu.common.security.config;

/**
 * 安全 & 租户过滤器执行顺序（全局唯一）
 *
 * <p>规则：
 * <ul>
 *   <li>数值越小，越早执行</li>
 *   <li>所有安全相关 Filter 必须在此定义</li>
 *   <li>禁止在各自 Filter 中硬编码 order</li>
 * </ul>
 */
public interface SecurityFilterOrders {

    /* ==================== 租户解析（最早） ==================== */

    /**
     * ClientId 解析（无 JWT 公共接口）
     */
    int PUBLIC_TENANT_FILTER = -210;

    /**
     * JWT 解析完成（Spring Security OAuth2 Resource Server）
     * 由 Spring 自动插入，此处仅为参考基准
     */
    int JWT_AUTH_FILTER = -200;

    /**
     * JWT 版本校验
     */
    int JWT_VERSION_FILTER = -190;

    /**
     * JWT 黑名单校验
     */
    int JWT_BLACKLIST_FILTER = -180;

    /**
     * 从 JWT 设置租户上下文（必须晚于 JWT）
     */
    int TENANT_FILTER = -170;

    /* ==================== Security 授权 ==================== */

    int EXCEPTION_TRANSLATION = -30;
    int AUTHORIZATION = -20;

    /* ==================== 清理（最晚） ==================== */

    int TENANT_CLEAR_FILTER = Integer.MAX_VALUE - 100;
}
```

✅ **所有 Filter 共用这一份**

✅ **顺序一目了然**

✅ **新人一看就懂**
