### ✅ 2️⃣ SecurityFilterChain：显式绑定 decoder（生死线）

```java
@Bean
public SecurityFilterChain securityFilterChain(
        HttpSecurity http,
        JwtDecoder jwtDecoder
) throws Exception {

    http
        .oauth2ResourceServer(rs -> rs
            .jwt(jwt -> jwt
                .decoder(jwtDecoder)
                .jwtAuthenticationConverter(jwtAuthenticationConverter())
            )
        );

    return http.build();
}
```
