## 三、为什么 DebugFilter 打印 Auth 还有，但 EntryPoint 说 null

顺序再复盘一次（你链里真实顺序）：

```
BearerTokenAuthenticationFilter   ✅ 设 JwtAuthenticationToken
DebugFilter                       ✅ 打印 Authentication 有
JwtVersionFilter                  ❌ 第89行抛 OAuth2AuthenticationException
ExceptionTranslationFilter        ❌ 清 SecurityContext → auth=null
MyAuthenticationEntryPoint        ❌ 打印 auth=null + “Token 非法”
```

这不是 Spring 精神分裂，是你 Filter 在“已认证”之后，用业务规则把请求掐死。

## 四、立刻止血方案（你选一个粘）

### ✅ 方案 A：改 claim 名（最推荐，直接对上 JWT）

把：
```java
Long userId = ClaimUtils.getClaimAsLong(jwt, JwtClaimConstants.User.ID);
```
改成：
```java
Long userId = ClaimUtils.getClaimAsLong(jwt, "memberId");
// 或你常量里叫 JwtClaimConstants.MEMBER_ID 之类
```

因为你的 JWT 明明白白写着：
```
"memberId": 10
```
