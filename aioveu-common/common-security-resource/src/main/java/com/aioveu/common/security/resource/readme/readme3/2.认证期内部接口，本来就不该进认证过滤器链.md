### ✅ 在 `aioveu-tenant` 里，统一规则

#### 1️⃣ `BearerTokenAuthenticationFilter`

如果你用的是 Spring Authorization Server / Resource Server：

```java
@Component
public class JwtAuthSkippingFilter extends OncePerRequestFilter {

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String uri = request.getRequestURI();
        return uri.startsWith("/aioveu/api/v8/admin/tenant/users/")
                && uri.contains("/UserAuthCredentials");
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) throws Exception {
        filterChain.doFilter(request, response);
    }
}
```

并确保 order 在 `BearerTokenAuthenticationFilter` 之前

---

#### 2️⃣ `JwtBlacklistFilter / JwtVersionFilter`

同样的 `shouldNotFilter` 逻辑：

```java
@Override
protected boolean shouldNotFilter(HttpServletRequest request) {

            && uri.contains("/UserAuthCredentials");
}
```
