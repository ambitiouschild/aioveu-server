## 一、这个报错的真相（一句话）

> ❌ `securityMatcher(...)`**不支持 `AntPathRequestMatcher`作为参数**
>
> ✅ `securityMatcher(...)`**只接受 `RequestMatcher`的“字符串版本”或 `RequestMatcher`数组**
>
> ✅ **但你不能直接传 `AntPathRequestMatcher`实例给它**

这是 **API 设计层面的限制**，不是你写错。

------

## 二、为什么 `securityMatcher`不能接 `AntPathRequestMatcher`？

### `securityMatcher`的方法签名是：

```
HttpSecurity securityMatcher(RequestMatcher... matchers)
```

看起来好像可以传 `AntPathRequestMatcher`对吧？

**但 Spring Security 6.x 的实现里：**

- 

  `securityMatcher(String... patterns)`✅ 支持

- 

  `securityMatcher(RequestMatcher... matchers)`✅ 理论上支持

- 

  **但很多 Spring Boot / Security 版本里，编译器会拒绝 AntPathRequestMatcher 实例**

👉 **这是一个已知“泛型 + 重载 + 编译器推导”的坑**

------

## 三、✅ 正确、稳定、生产级写法（你直接照抄）

### ✅ 方案一（✅ 最推荐，最简单，最稳）

> **`securityMatcher`只用字符串**
>
> **内部 `requestMatchers`才用 `AntPathRequestMatcher`**

------

### ✅ tenantPublicChain（公共接口链）

```
@Bean
@Order(1)
public SecurityFilterChain tenantPublicChain(HttpSecurity http) throws Exception {
    http
        // ✅ 这里只用字符串
        .securityMatcher(
            "/aioveu/api/v8/admin/tenant/users/tenants/**",
            "/aioveu/api/v8/admin/tenant/users/**/authInfo",
            "/aioveu/api/v8/admin/tenant/users/**/UserAuthCredentials"
        )
        .authorizeHttpRequests(auth -> auth
            .anyRequest().permitAll()
        )
        .csrf(AbstractHttpConfigurer::disable);

    return http.build();
}
```

------

### ✅ tenantResourceChain（JWT 接口链）

```
@Bean
@Order(2)
public SecurityFilterChain tenantResourceChain(HttpSecurity http) throws Exception {

    http
        // ✅ 这里只用字符串
        .securityMatcher("/aioveu/api/v8/admin/tenant/**")
        .authorizeHttpRequests(auth -> auth
            .requestMatchers(
                AntPathRequestMatcher.antMatcher(
                    "/aioveu/api/v8/admin/tenant/users/me"
                )
            ).authenticated()
            .anyRequest().authenticated()
        )
        .oauth2ResourceServer(oauth2 -> oauth2.jwt())
        .addFilterAfter(jwtVersionFilter, BearerTokenAuthenticationFilter.class)
        .addFilterAfter(jwtBlacklistFilter, BearerTokenAuthenticationFilter.class)
        .addFilterAfter(tenantFilter, BearerTokenAuthenticationFilter.class)
        .csrf(AbstractHttpConfigurer::disable);

    return http.build();
}
```

✅ **编译通过**

✅ **启动不炸**

✅ **Spring Security 6.x 官方推荐姿势**

✅ **不会再出现 `cannot decide whether these patterns are Spring MVC patterns`**

## 四、为什么这是“唯一正确姿势”？（重点）

### ✅ `securityMatcher(String...)`

👉 **用来决定：这条链“要不要处理这个请求”**

- 

  只关心 URL

- 

  不关心 MVC

- 

  不关心 HandlerMapping

- 

  性能最好

- 

  语义最清晰

### ✅ `requestMatchers(AntPathRequestMatcher)`

👉 **用来做：授权决策**

- 

  是否 permitAll

- 

  是否 authenticated

- 

  是否 hasRole

**职责分离，非常干净**
