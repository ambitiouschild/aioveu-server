## 一、为什么你会看到这个错（钉死原因）

你贴的 `ResourceServerConfiguration` 里：

```java
public SecurityFilterChain tenantResourceChain(
        HttpSecurity http,
        JwtBlacklistFilter jwtBlacklistFilter,
        JwtVersionFilter jwtVersionFilter,
        TenantFilter tenantFilter,
        DebugFilter debugFilter,
        ResourceSecurityProperties resourceSecurityProperties
) throws Exception {
```

❌ 方法参数里没有 `clientIdTenantFilterProvider`  
但你在方法体里写了：

```java
.addFilterBefore(
    clientIdTenantResolutionFilter,
    BearerTokenAuthenticationFilter.class
)
```

或者（按我上一轮伪代码）：

```java
clientIdTenantFilterProvider.getIfAvailable();
```

👉 Java 编译器直接说：这符号不存在
👉 这不是 Spring 问题，是编译期类型不存在

而且你之前自己说了：
> 这两个模块不依赖，导入不了

所以：
• ❌ 不能写 `ClientIdTenantResolutionFilter` 类型

• ❌ 不能写它的 `ObjectProvider<ClientIdTenantResolutionFilter>`

• ✅ 只能写两个模块都能看见的父类型


---

## 二、唯一能编译、且不破坏边界的写法（复制即用）

### ✅ 改你的 `tenantResourceChain` 方法签名

把参数里加这一行（注意类型）：

```java
ObjectProvider<OncePerRequestFilter> clientIdTenantFilterProvider
```

完整方法头示例：

```java
@Bean
@Order(0)
public SecurityFilterChain tenantResourceChain(
        HttpSecurity http,

        ObjectProvider<OncePerRequestFilter> clientIdTenantFilterProvider,

        JwtBlacklistFilter jwtBlacklistFilter,
        JwtVersionFilter jwtVersionFilter,
        TenantFilter tenantFilter,
        DebugFilter debugFilter,
        ResourceSecurityProperties resourceSecurityProperties
) throws Exception {
```

---

### ✅ 在方法体里这样用（不 import tenant 类型）

```java
OncePerRequestFilter clientIdTenantFilter =
        clientIdTenantFilterProvider.getIfAvailable();

if (clientIdTenantFilter != null) {
    http.addFilterBefore(
        clientIdTenantFilter,
        BearerTokenAuthenticationFilter.class
    );
}
```

---

## 三、为什么 `OncePerRequestFilter` 能写，而你的 Filter 不能写

| 类型                             | 所在模块      | resource 能否写   |
| -------------------------------- | ------------- | ----------------- |
| `OncePerRequestFilter`           | spring-web    | ✅                 |
| `JwtBlacklistFilter`             | resource 模块 | ✅                 |
| `TenantFilter`                   | resource 模块 | ✅                 |
| `ClientIdTenantResolutionFilter` | tenant 模块   | ❌ 不依赖 → 不能写 |

✅ `ObjectProvider<OncePerRequestFilter>` 是编译可过、运行可配

## 四、tenant 模块里你只需要保证这一句

```java
@Component
public class ClientIdTenantResolutionFilter
        extends OncePerRequestFilter {
}
```

Spring 容器会把它当作 `OncePerRequestFilter` Bean 推出来。
