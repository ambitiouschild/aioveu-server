## ✅ 方式一（✅ 最推荐、最正统、最稳）

### ✅ 直接注入 `OAuth2ResourceServerProperties`

这是 Spring Boot 官方预留的钩子，100% 对齐你的 yml。

### 1️⃣ 不需要任何额外配置
只要你 yml 里有：

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          jwk-set-uri: ${gateway.endpoint}/oauth2/jwks
```

### 2️⃣ 在 `ResourceServerConfiguration` 里直接注入

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
@RequiredArgsConstructor
@Slf4j
public class ResourceServerConfiguration {

    private final OAuth2ResourceServerProperties resourceServerProperties;

    @Bean
    public JwtDecoder jwtDecoder() {

        // ✅ 直接拿到 yml 里的 jwk-set-uri
        String jwkSetUri = resourceServerProperties.getJwt().getJwkSetUri();

        log.info("🔑 Loaded jwk-set-uri from spring config: {}", jwkSetUri);

        NimbusJwtDecoder decoder = NimbusJwtDecoder
                .withJwkSetUri(jwkSetUri)
                .build();

        // ✅ 关闭 audience 校验（多微服务共用 jar）
        decoder.setJwtValidator(
            new DelegatingOAuth2TokenValidator<>(
                JwtValidators.createDefault(),
                jwt -> OAuth2TokenValidatorResult.success()
            )
        );

        return decoder;
    }
}
```

✅ 优点
• ✅ 官方 API

• ✅ 支持占位符 `${}`、环境变量

• ✅ 支持 Relaxed Binding

• ✅ Spring Boot 升级不炸

• ✅ 不需要你自己写 `SecurityProperties`


👉 你现在的项目，直接用这个就行

## ✅ 方式二（✅ 也可以用，但不如方式一优雅）

### ✅ 用 `@Value` 直接注入 yml 值

```java
@Value("${spring.security.oauth2.resourceserver.jwt.jwk-set-uri}")
private String jwkSetUri;
```

用在 `JwtDecoder` 里：

```java
@Bean
public JwtDecoder jwtDecoder() {

    NimbusJwtDecoder decoder = NimbusJwtDecoder
            .withJwkSetUri(jwkSetUri)
            .build();

    decoder.setJwtValidator(
        new DelegatingOAuth2TokenValidator<>(
            JwtValidators.createDefault(),
            jwt -> OAuth2TokenValidatorResult.success()
        )
    );

    return decoder;
}
```

⚠️ 缺点
• ❌ 不支持类型安全

• ❌ 拼写错误启动才发现

• ❌ 不支持复杂对象（audiences 之类）

• ❌ 重构不友好


👉 能用，但不推荐在公共 starter 里用

## ✅ 方式三（❌ 不推荐，但很多人误用）

### ❌ 自己再包一层 `SecurityProperties`

```java
@ConfigurationProperties(prefix = "security")
public class SecurityProperties {
    private String jwkSetUri;
}
```

然后 yml 里再写一遍：

```yaml
security:
  jwk-set-uri: ${spring.security.oauth2.resourceserver.jwt.jwk-set-uri}
```

❌ 问题
• 重复配置

• 容易不一致

• 多环境维护成本高

• 和 Spring 原生配置脱节


👉 你前面那种“卡住”的情况，很多就是这么来的

## ✅ 你这个场景的「最终推荐方案」

### ✅ 代码里获取 `jwk-set-uri` 的正确姿势

```java
private final OAuth2ResourceServerProperties resourceServerProperties;

@Bean
public JwtDecoder jwtDecoder() {
    String jwkSetUri = resourceServerProperties.getJwt().getJwkSetUri();

    NimbusJwtDecoder decoder =
            NimbusJwtDecoder.withJwkSetUri(jwkSetUri).build();

    // ✅ 多微服务共用 jar：关 aud
    decoder.setJwtValidator(
        new DelegatingOAuth2TokenValidator<>(
            JwtValidators.createDefault(),
            jwt -> OAuth2TokenValidatorResult.success()
        )
    );

    return decoder;
}
```
