你的 log：

### ✅ 3️⃣ 正确写法：按 Bean 名字拿（不破坏边界）

因为：

• `@Component` 在 tenant 模块

• Bean 默认名：`clientIdTenantResolutionFilter`

• resource 模块可以不 import 类，但可以用字符串名字


改成这样（复制即用）：

```java
OncePerRequestFilter clientIdTenantFilter =
        applicationContext.getBean("clientIdTenantResolutionFilter", OncePerRequestFilter.class);
```

并用 try/catch 包住：

```java
OncePerRequestFilter clientIdTenantFilter = null;
try {
    clientIdTenantFilter = applicationContext.getBean(
            "clientIdTenantResolutionFilter", OncePerRequestFilter.class);
} catch (NoSuchBeanDefinitionException e) {
    // tenant 模块不存在，直接跳过
}

log.error("🚨 clientIdFilter present: {}", clientIdTenantFilter != null);

if (clientIdTenantFilter != null) {
    http.addFilterBefore(
        clientIdTenantFilter,
        BearerTokenAuthenticationFilter.class
    );
}
```

✅ 不 import tenant 类  
✅ 精确命中目标 Filter  
✅ 无 tenant 模块时不炸
