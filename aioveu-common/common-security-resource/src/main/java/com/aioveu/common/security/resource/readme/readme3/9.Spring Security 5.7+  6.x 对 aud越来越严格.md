## 二、为什么“之前没出现过”？——最可能的 5 个历史真相

我按出现概率从高到低给你拆。

---

### ✅ 原因 1（90%）：你之前 **没开启 / 没生效 `aud` 校验**

#### 之前可能是这样的：

```java
.oauth2ResourceServer(rs -> rs
    .jwt(jwt -> jwt
        // ❌ 没有配置 audienceValidator
    )
);
```

或者：

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          # ❌ 没配 audiences
```

👉 Spring Security 默认：
• ✅ 校验 `iss`

• ✅ 校验 `exp`

• ❌ 不校验 `aud`（老版本 / 默认行为）


#### 现在变成这样了（你可能无意中打开了）：

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          audiences: aioveu-tenant
```

或者你升级了 Spring Boot / Spring Security：

> Spring Security 5.7+ / 6.x 对 `aud` 越来越严格

✅ 之前能跑：没校验
✅ 现在炸：校验生效了

👉 这是最最常见的原因

---

### ✅ 原因 2：Authorization Server 升级 / 配置变更（非常常见）

#### 之前签发的是：

```json
{
  "aud": "aioveu-tenant"
}
```

#### 现在变成了：

```json
{
  "aud": "mall-admin"
}
```

为什么会发生？

✅ 你改了：
• client 的 `scope`

• client 的 `audience` 配置

• Token enhancer / Customizer

• Spring Authorization Server 升级


👉 Token 变了，但你没意识到
👉 Resource Server 还在用旧的 `aud` 期望

---

### ✅ 原因 3：你之前用的是 **opaque token**，现在变成 **JWT**

#### 之前：

```yaml
oauth2:
  resourceserver:
    opaque-token:
      introspection-uri: ...
```

👉 Introspection 不校验 `aud`
👉 只要 token 有效就能过

#### 现在：

```yaml
oauth2:
  resourceserver:
    jwt:
      issuer-uri: ...
```

👉 JWT 强制校验 `aud`
👉 直接炸

---

### ✅ 原因 4：你之前 `/me` 根本没走这套 Filter 链

有可能之前：

• `/me` 在白名单

• 或者走了不同的 `SecurityFilterChain`

• 或者 `TenantFilter` 还没加 / 没启用


👉 你以为“之前一样”，其实链路已经变了

---

### ✅ 原因 5：你之前用的是 **内部 Feign Token**

比如：

• Feign 用的是 `client_credentials`

• `aud = mall-admin`

• 但接口在白名单 / 内部调用


👉 你以为是“同一个 Token”
👉 其实根本不是一回事

---

## 三、为什么你现在这个现象“特别像之前没问题”？

因为：

✅ Token 能解析
✅ Header 正确
✅ JWT 没过期
✅ `tenant_id` 还在
✅ 业务还能查数据

👉 一切看起来都对
👉 只有 `aud` 不对

而 Spring Security 默认不告诉你 `aud` 校验失败
👉 直到你的 `TenantFilter` 把它捅出来

## 四、怎么 100% 确认“之前为啥没问题”？


| 字段    | 旧 Token | 新 Token     |
| ------- | -------- | ------------ |
| `aud`   | ?        | `mall-admin` |
| `iss`   | ?        | ?            |

---

### ✅ 2️⃣ 看 Git 历史（最直接）

```bash
git log --oneline -p -- your-security-config.java
git log --oneline -p -- application.yml
```

重点看：
• `audiences`

• `audienceValidator`

• Spring Boot / Security 版本升级

```text

```
