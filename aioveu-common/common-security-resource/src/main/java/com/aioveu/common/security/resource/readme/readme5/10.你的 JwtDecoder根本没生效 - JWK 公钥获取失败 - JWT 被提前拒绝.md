## 三、真正的根因（你现在踩的就是这个）

### ❌ 你把 `JwtBlacklistFilter` 插在了 **JWT 认证之前**

```java

.addFilterAfter(jwtBlacklistFilter, BearerTokenAuthenticationFilter.class)
```

### 但问题不在于顺序本身

👉 问题在于：

> `JwtBlacklistFilter` / `JwtVersionFilter` 被提前执行
> 而 `BearerTokenAuthenticationFilter` 在某种条件下“放弃解析 JWT”

## 四、99% 概率的真实原因（逐条对号入座）

---

### ✅ ✅ ✅ 原因 ①（最可能）：`issuer-uri` / `jwk-set-uri` 不一致

你的 JWT 里：

```json
"iss": "http://192.168.1.3:9000"
```

但你配置文件里是：

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          jwk-set-uri: ${gateway.endpoint}/oauth2/jwks
          issuer-uri: http://192.168.1.3:9000
```

⚠️ Spring Security 会校验：

• issuer 是否一致

• JWK kid 是否存在

• JWK 是否能从网关地址拿到


只要有一项失败：

• ❌ JWT 不解析

• ❌ Authentication == null

• ❌ 不抛异常

• ❌ 直接进入你的 TenantFilter


✅ 这是最符合你日志的表现

---

### ✅ 验证方式（立刻就能确认）

在 `application.yml` 里 临时关闭 issuer 校验：

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          jwk-set-uri: http://192.168.1.3:9000/oauth2/jwks
          # issuer-uri: http://192.168.1.3:9000
```

或者在 JVM 启动参数加：

```bash
-Dspring.security.oauth2.resourceserver.jwt.issuer-uri=
```

👉 如果这一改就通了，根因就是这个

---

### ✅ 原因 ②：JWK 公钥获取失败（网关 / 网络 / Redis）

你的架构是：

```
网关 → 微服务 → jwk-set-uri → 网关 → 认证服务 → Redis
```

只要有一次：

• 网关转发失败

• Redis 里 JWK 不存在

• kid 不匹配


👉 JWT 直接被静默拒绝

✅ 验证方式：

在日志级别打开：

```yaml
logging:
  level:
    org.springframework.security.oauth2.jwt: DEBUG
    org.springframework.security.oauth2.server.resource: TRACE
```

你会看到类似：

```text
Unable to find JWK with kid = e1e56336-03de-4220-b7f6-442829ca0242
```

---

### ✅ 原因 ③（你代码里的高风险点）

你这里有：

```java
http.oauth2ResourceServer(resourceServerConfigurer ->
    resourceServerConfigurer
        .jwt(jwtConfigurer -> jwtAuthenticationConverter())
);
```

⚠️ 你没有显式配置 `JwtDecoder` Bean
⚠️ 你也没有关闭 `issuer` 校验
⚠️ Spring Boot 自动配置的 `JwtDecoder` 可能因为 issuer / jwk 问题直接放弃解析

✅ 生产级正确写法应该是：

```java
@Bean
public JwtDecoder jwtDecoder() {
    NimbusJwtDecoder decoder = NimbusJwtDecoder
        .withJwkSetUri("http://192.168.1.3:9000/oauth2/jwks")
        .build();
    decoder.setJwtValidator(JwtValidators.createDefault());
    return decoder;
}
```
