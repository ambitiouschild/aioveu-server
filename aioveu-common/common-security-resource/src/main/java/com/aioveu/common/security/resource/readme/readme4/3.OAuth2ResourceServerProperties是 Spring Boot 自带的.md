## ✅ 它在哪？（你不用自己建）

这个类在 Spring Boot 的自动配置包里：

```java
org.springframework.boot.autoconfigure.security.oauth2.resource.OAuth2ResourceServerProperties
```

（Spring Security 5.7+ / Boot 2.7+ / Boot 3.x 都是这个路径）

---

## ✅ 你需要做什么？（只有两步）

### ✅ 第一步：确保你有这个依赖

Spring Boot 2.x / 3.x 通用

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-oauth2-resource-server</artifactId>
</dependency>
```

✅ 有了这个依赖，`OAuth2ResourceServerProperties` 就会被自动注册成 Configuration Bean

---

### ✅ 第二步：直接在配置类里注入（你已经在用 Lombok ✅）

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
@RequiredArgsConstructor
@Slf4j
public class ResourceServerConfiguration {

    // ✅ 直接注入，不用写任何额外代码
    private final OAuth2ResourceServerProperties resourceServerProperties;

    @Bean
    public JwtDecoder jwtDecoder() {

        String jwkSetUri = resourceServerProperties.getJwt().getJwkSetUri();

        log.info("🔑 Loaded jwk-set-uri = {}", jwkSetUri);

        NimbusJwtDecoder decoder =
                NimbusJwtDecoder.withJwkSetUri(jwkSetUri).build();

        // ✅ 关闭 audience 校验
        decoder.setJwtValidator(
            new DelegatingOAuth2TokenValidator<>(
                JwtValidators.createDefault(),
                jwt -> OAuth2TokenValidatorResult.success()
            )
        );

        return decoder;
    }
}
```

✅ 这就完了
✅ 不需要 `@EnableConfigurationProperties`
✅ 不需要 `@ConfigurationProperties`
✅ 不需要自己写 Properties 类
