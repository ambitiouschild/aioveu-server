## 二、你之前那个“自己解析”的过滤器，长什么样？（我给你还原一下）

```java
public class OldTenantFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(...) {

        // ✅ 自己从 header 拿 token
        String token = resolveToken(request);

        // ✅ 自己解析 JWT（不走 Spring Security 认证）

        // ✅ 自己塞上下文

    }
}
```
