# ✅ 那为什么还会炸？

因为：

> `BearerTokenAuthenticationFilter` 的职责到这就结束了
>
> ✅ 它只负责：
> - 解析 JWT
> - 构建 `JwtAuthenticationToken`
> - 放进 `SecurityContext`
>
> ❌ 它不负责：
> - 设置 `TenantContextHolder`
> - 管 MP 租户插件
> - 管 ThreadLocal 生命周期
