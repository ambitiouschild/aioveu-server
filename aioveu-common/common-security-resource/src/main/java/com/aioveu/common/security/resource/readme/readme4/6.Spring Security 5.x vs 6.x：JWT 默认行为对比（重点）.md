## 二、Spring Security 5.x vs 6.x：JWT 默认行为对比（重点）

| 行为                 | Spring Security 5.8 | Spring Security 6.x |
| -------------------- | ------------------- | ------------------- |

| `aud` 校验           | ❌ 默认不校验        | ✅ 默认强制校验      |

## 六、✅ 你现在这套架构的「唯一正确解法」（版本无关）

### ✅ 明确告诉 Spring：“我负责 JWT 校验规则”

```java
@Bean
public JwtDecoder jwtDecoder(OAuth2ResourceServerProperties props) {
    return NimbusJwtDecoder
            .withJwkSetUri(props.getJwt().getJwkSetUri())
            .build();
}
```

```java
@Bean
public SecurityFilterChain securityFilterChain(
        HttpSecurity http,
        JwtDecoder jwtDecoder
) throws Exception {

    http
        .oauth2ResourceServer(rs -> rs
            .jwt(jwt -> jwt
                .decoder(jwtDecoder) // ✅ 显式绑定
                .jwtAuthenticationConverter(jwtAuthenticationConverter())
            )
        );

    return http.build();
}
```

✅ 这是 6.x 的“标准姿势”
✅ 不会再被版本升级坑
