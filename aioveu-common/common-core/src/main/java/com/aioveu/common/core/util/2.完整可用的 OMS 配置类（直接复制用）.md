啊哈，这个报错信息直接告诉你问题了 👍

你用的 MyBatis-Plus 版本是 3.5.x，所以 `ConfigurationCustomizer` 接口里的抽象方法签名变了：

| 版本    | 方法签名                                                     |
| ------- | ------------------------------------------------------------ |
| ≤ 3.4.x | `void customize(org.apache.ibatis.session.Configuration)`    |
| ≥ 3.5.0 | `void customize(com.baomidou.mybatisplus.core.MybatisConfiguration)` |

你的匿名类实现的是旧的 `customize(Configuration)`，但接口要求的是 `customize(MybatisConfiguration)` → 所以 IDE 说"你必须实现 `customize(MybatisConfiguration)`"。

---

## ✅ 正确的写法（MyBatis-Plus 3.5.x）

### 写法一：Lambda（最简洁，推荐）

```java
import com.baomidou.mybatisplus.core.MybatisConfiguration;
import com.baomidou.mybatisplus.spring.boot.autoconfigure.ConfigurationCustomizer;

@Bean
public ConfigurationCustomizer omsTypeHandlerConfig() {
    return (MybatisConfiguration configuration) -> configuration.getTypeHandlerRegistry()
        .register(PaymentMethodEnum.class, PaymentMethodEnumOrdinalTypeHandler.class);
}
```

### 写法二：匿名内部类（完整版）

```java
import com.baomidou.mybatisplus.core.MybatisConfiguration;
import com.baomidou.mybatisplus.spring.boot.autoconfigure.ConfigurationCustomizer;

@Bean
public ConfigurationCustomizer omsTypeHandlerConfig() {
    return new ConfigurationCustomizer() {
        @Override
        public void customize(MybatisConfiguration configuration) {
            configuration.getTypeHandlerRegistry()
                .register(PaymentMethodEnum.class, PaymentMethodEnumOrdinalTypeHandler.class);
        }
    };
}
```

## 🔑 关键：import 一定要对

你现在的 import 大概率是旧的：

```java
// ❌ 旧的，3.5.x 里这个方法签名不匹配
import org.mybatis.spring.boot.autoconfigure.ConfigurationCustomizer;
```

改成：

```java
// ✅ 3.5.x 的正确路径
import com.baomidou.mybatisplus.spring.boot.autoconfigure.ConfigurationCustomizer;
```

## 📦 完整可用的 OMS 配置类（直接复制用）

```java
package com.aioveu.oms.config;

import com.aioveu.common.core.enums.pay.PaymentMethodEnum;
import com.aioveu.common.core.enums.pay.PaymentChannelEnum;
import com.aioveu.oms.handler.PaymentMethodEnumOrdinalTypeHandler;
import com.aioveu.oms.handler.PaymentChannelEnumOrdinalTypeHandler;
import com.baomidou.mybatisplus.spring.boot.autoconfigure.ConfigurationCustomizer;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class OmsMybatisConfig {

    @Bean
    public ConfigurationCustomizer omsTypeHandlerConfig() {
        return configuration -> {
            configuration.getTypeHandlerRegistry()
                    .register(PaymentMethodEnum.class, PaymentMethodEnumOrdinalTypeHandler.class);
            configuration.getTypeHandlerRegistry()
                    .register(PaymentChannelEnum.class, PaymentChannelEnumOrdinalTypeHandler.class);
        };
    }
}
```

PAY 服务的配置类同理，只是换成 `CodeTypeHandler` 和对应的 import。
