## 一、你这句话，是“架构师级结论”

> API 用 core，Boot 用 resource

我给你翻译成 Spring 官方语言：

| 角色                                   | 该用谁                       | 原因                             |
| -------------------------------------- | ---------------------------- | -------------------------------- |
| Feign API / DTO / Enum                 | ✅ `common-security-core`     | API 层只定义契约，不关心 Web     |
| Spring Boot 启动类（auth / oms / pay） | ✅ `common-security-resource` | 资源服务器需要 Filter / Resolver |
| 业务 Service / Repository              | ✅ `common-security-core`     | 只依赖模型与接口                 |
| Web / Filter / Handler                 | ✅ `common-security-resource` | 只有 resource 知道 HTTP          |

👉 你现在的理解，已经完全踩在点上了。

---

## 二、为什么这是“对的”（而不是凑合用）

### ✅ 1️⃣ API 层（tenant-api / order-api）

```java
// tenant-api/pom.xml
dependencies {
    implementation 'com.aioveu:common-security-core'
}
```

API 里只有：

• `Result<T>`

• `UserAuthCredentials`

• `TenantFeignClient`

• `SecurityCoreProperties`（只读配置）


❌ 不能有：
• Filter

• Interceptor

• WebSecurityConfigurerAdapter

• HttpServletRequest


✅ API 是“干净的契约”

---

### ✅ 2️⃣ Boot 应用（auth / oms / pay）

```java
// aioveu-tenant-pay/pom.xml
dependencies {
    implementation 'com.aioveu:common-security-resource'
}
```

Boot 应用里才有：

• `PublicTenantFilter`

• `PublicTenantResolver`

• `SecurityResourceProperties`

• `JwtAuthenticationConverter`

• `AccessDeniedHandler`


✅ Boot 负责“把安全跑起来”

## 三、一个非常清晰的“依赖图”（你照着画）

```
tenant-api
└── common-security-core ✅（契约）

order-api
└── common-security-core ✅（契约）

aioveu-auth
└── common-security-resource ✅（认证服务器）

aioveu-oms
└── common-security-resource ✅（资源服务器）

aioveu-pay
└── common-security-resource ✅（资源服务器）

common-security-resource
└── common-security-core ✅（实现依赖）
```

👉 没有任何一个 Boot 服务直接依赖 core
👉 没有任何一个 API 依赖 resource

## 四、为什么你之前会“绕晕”？

因为你之前：

• core 里有 `SecurityProperties`

• resource 里也有 `SecurityProperties`

• API 不知道该依赖谁

• Boot 也不知道该扫谁


👉 现在你删掉了 core 里的那个
👉 边界就清楚了

## 五、给你一个“铁律”（以后照着用）

> ✅ 凡是 `common-*-core`
> - 放模型
> - 放接口
> - 放 DTO
> - 放 Enum
> - 放配置属性
>
> ✅ 凡是 `common-*-resource / starter`
> - 放 Filter
> - 放 Interceptor
> - 放 AutoConfiguration
> - 放 Web 相关 Bean
>
> ❌ core 不依赖 resource
> ✅ resource 依赖 core
