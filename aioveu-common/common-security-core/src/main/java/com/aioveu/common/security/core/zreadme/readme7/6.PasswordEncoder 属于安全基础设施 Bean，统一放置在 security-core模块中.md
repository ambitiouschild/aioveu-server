## 一、你说的 `security-core`是啥？（先对齐概念）

我按行业通用命名习惯来理解你口中的 `security-core`：

```
aioveu-security-core
├── config
│   └── SecurityBeanConfig.java   ✅
├── jwt
├── encoder
├── tenant
└── properties
```

如果这个模块的定位是：

✅ 放 **Spring Security 的基础设施 Bean**

✅ 被 **auth / resource / user / gateway** 依赖

✅ 不包含 Controller / API / 业务逻辑

👉 **那它就是“完全正确”的存放位置**

------

## 二、✅ PasswordEncoder 放 `security-core`：完全正确

### ✅ 推荐写法（只放一份）

```
@Configuration
public class SecurityBeanConfig {

    @Bean
    public PasswordEncoder passwordEncoder() {
        return PasswordEncoderFactories.createDelegatingPasswordEncoder();
    }
}
```

### ✅ 模块依赖关系（非常关键）

```
aioveu-auth-server
 └── depends on → aioveu-security-core

aioveu-resource-server
 └── depends on → aioveu-security-core

aioveu-user-service
 └── depends on → aioveu-security-core
```

✅ **全 JVM / 全容器：只有这一个 PasswordEncoder Bean**

------

## 三、那为什么不是这些地方？

| 位置              | 是否放 PasswordEncoder | 原因                            |
| ----------------- | ---------------------- | ------------------------------- |
| `security-core`✅  | ✅ **强烈推荐**         | 基础设施、全局唯一              |
| `security-api`    | ❌                      | API 模块，不启动 Spring Context |
| `auth-biz`        | ❌                      | 业务模块，会被多模块重复引入    |
| `resource-server` | ❌                      | 只鉴权，不碰密码                |
| `user-service`    | ❌                      | 业务模块                        |
| `gateway`         | ⚠️ 不推荐               | 网关一般不处理密码              |

------

## 四、`security-core`这个名字好在哪？

### ✅ 行业共识命名

| 模块名            | 含义                  |
| ----------------- | --------------------- |
| `security-core`   | 安全核心（基础设施）✅ |
| `security-api`    | 安全对外 API          |
| `security-common` | 安全公共工具          |
| `common-security` | 等价，也很常用        |

👉 **你用 `security-core`没有任何问题，反而很专业**

------

## 五、security-core 里还能放什么？（顺便帮你规划）

✅ **非常适合放这些 Bean：**

```

JwtDecoder / JwtEncoder
SecurityProperties
TenantSecurityFilter
SecurityEventPublisher
AccessDeniedHandler
AuthenticationEntryPoint
```

❌ **不适合放这些：**

```
LoginController
UserServiceImpl
Feign Client
业务 DTO
```
