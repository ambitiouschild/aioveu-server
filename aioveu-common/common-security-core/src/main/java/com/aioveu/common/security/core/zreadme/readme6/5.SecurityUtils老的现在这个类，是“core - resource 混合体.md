## ✅ 1️⃣ `SecurityUtils`（留在 core，但**大幅瘦身**）

📦 位置：
```
common-security-core
└── util
    └── SecurityUtils.java
```

✅ 只允许：
• `SecurityContextHolder`

• `Authentication`

• `SysUserDetails`

• `TenantContextHolder`


❌ 禁止：
• `Jwt`

• `HttpServletRequest`

• `RequestContextHolder`

• `getToken()`


### ✅ 瘦身后的 `SecurityUtils`（core 版）

```java
@Slf4j
public final class SecurityUtils {

    private SecurityUtils() {}

    public static Authentication getAuthentication() {
        return SecurityContextHolder.getContext().getAuthentication();
    }

    public static Optional<SysUserDetails> getUser() {
        Authentication authentication = getAuthentication();
        if (authentication == null) {
            return Optional.empty();
        }
        if (authentication.getPrincipal() instanceof SysUserDetails userDetails) {
            return Optional.of(userDetails);
        }
        return Optional.empty();
    }

    public static Long getUserId() {
        return getUser().map(SysUserDetails::getUserId).orElse(null);
    }

    public static String getUsername() {
        return getUser().map(SysUserDetails::getUsername).orElse(null);
    }

    public static Long getTenantId() {
        // 1️⃣ JWT 中的（已认证）
        Long jwtTenantId = getUser().map(SysUserDetails::getTenantId).orElse(null);
        if (jwtTenantId != null) {
            return jwtTenantId;
        }
        // 2️⃣ 公共接口 / 系统态
        return TenantContextHolder.getTenantId();
    }

    public static boolean canSwitchTenant() {
        return getUser()
                .map(SysUserDetails::getCanSwitchTenant)
                .orElse(false);
    }

    public static boolean isRoot() {
        Set<String> roles = getRoles();
        return roles != null && roles.contains(SystemConstants.ROOT_ROLE_CODE);
    }

    public static Set<String> getRoles() {
        return getUser()
                .map(SysUserDetails::getAuthorities)
                .orElse(Collections.emptySet())
                .stream()
                .map(GrantedAuthority::getAuthority)
                .filter(a -> a.startsWith(SecurityConstants.ROLE_PREFIX))
                .map(a => StrUtil.removePrefix(a, SecurityConstants.ROLE_PREFIX))
                .collect(Collectors.toSet());
    }
}
```

✅ core 里没有 JWT
✅ core 里没有 Web
✅ core 只信任 `SysUserDetails`

## ✅ 2️⃣ `JwtSecurityHelper`（搬到 resource）

📦 位置：
```
common-security-resource
└── util
    └── JwtSecurityHelper.java
```

✅ 负责：
• JWT Claims

• Token 解析

• HTTP Header

• Request 上下文


### ✅ `JwtSecurityHelper`（resource 版）

```java
@Slf4j
public final class JwtSecurityHelper {

    private JwtSecurityHelper() {}

    public static Map<String, Object> getTokenAttributes() {
        Authentication authentication = SecurityUtils.getAuthentication();
        if (authentication instanceof JwtAuthenticationToken jwtAuth) {
            return jwtAuth.getToken().getClaims();
        }
        return Collections.emptyMap();
    }

    public static String getJti() {
        return (String) getTokenAttributes().get(JwtClaimConstants.Token.JTI);
    }

    public static String getToken() {
        ServletRequestAttributes attrs =
                (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
        if (attrs == null) {
            return null;
        }
        String auth = attrs.getRequest().getHeader(HttpHeaders.AUTHORIZATION);
        if (StrUtil.isNotBlank(auth) && auth.startsWith(SecurityConstants.BEARER_TOKEN_PREFIX)) {
            return auth.substring(SecurityConstants.BEARER_TOKEN_PREFIX.length()).trim();
        }
        return null;
    }

    public static String getClientId() {
        return (String) getTokenAttributes().get(JwtClaimConstants.Client.ID);
    }

    public static Long getExp() {
        return Convert.toLong(getTokenAttributes().get("exp"));
    }
}
```

✅ 只在 resource 里用
✅ 可以安全依赖 JWT / Web
✅ 业务代码不再混淆

## 五、你现在这个 `SecurityUtils` 的“原罪”

你这个类最大的问题是：

```java
if (principal instanceof Jwt) {
    // 从 JWT 构建 SysUserDetails
}
```

❌ core 不应该“临时构建” `SysUserDetails`
❌ `SysUserDetails` 必须在认证阶段构建好
❌ core 只能“读”，不能“猜”

👉 这是你之前所有 JWT 问题的根源
