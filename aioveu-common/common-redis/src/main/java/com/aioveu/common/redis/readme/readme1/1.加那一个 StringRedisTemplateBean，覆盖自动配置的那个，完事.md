**不需要再配一个。**

你现在的问题恰恰是：**你已经有一个 `StringRedisTemplate`了，但它被 Redisson 的 ConnectionFactory "暗搓搓"改了行为。**

所以你有两个选择：

------

## ✅ 选择一（推荐）：就配一个，覆盖掉 Spring Boot 自动创建的那个

你**不需要新增 Bean 名字**，就**覆盖**它：

```
@Configuration
public class RedisConfiguration {

    // 你已有的 RedisTemplate<String, Object> 保留不动
    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory redisConnectionFactory) {
        // ... 你原来的代码不动
    }

    // ✅ 新增这一个，专门管 StringRedisTemplate
    @Bean
    public StringRedisTemplate stringRedisTemplate(RedisConnectionFactory connectionFactory) {
        StringRedisTemplate template = new StringRedisTemplate();
        template.setConnectionFactory(connectionFactory);
        template.setKeySerializer(RedisSerializer.string());
        template.setValueSerializer(RedisSerializer.string());
        template.setHashKeySerializer(RedisSerializer.string());
        template.setHashValueSerializer(RedisSerializer.string());
        template.afterPropertiesSet();
        return template;
    }
}
```

**效果：**

| 之前                                                         | 之后                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| Spring Boot 自动创建 `StringRedisTemplate`，底层用 Redisson 的 Codec | 你手动定义了 `StringRedisTemplate`，**序列化器被你强制锁死为 `String`** |
| Redisson 偷偷把 value 当 JSON 处理 → 返回 `null`             | 你的 `RedisSerializer.string()`直接读写 UTF-8 字节 → **永远是纯文本** |

✅ **Bean 名字还是 `stringRedisTemplate`**

✅ **你 Filter 里 `@Autowired StringRedisTemplate stringRedisTemplate`不用改一行**

✅ **只多了一个 Bean 方法**

------

## ✅ 选择二（更懒）：什么都不配，直接改 Redisson 的 Codec

如果你不想多加 Bean，就在 Redisson 配置文件（或者 `redisson.yaml`/ `redisson.json`）里加一行：

```
codec: org.redisson.codec.StringCodec
```

或者你用的是 `application.yml`里的 `spring.data.redis.redisson.config`方式，确保 Codec 是 `StringCodec`。

------

## ❌ 不要做的事

| 做法                                       | 为什么不行                                                   |
| ------------------------------------------ | ------------------------------------------------------------ |
| 再注入一个 `StringRedisTemplate`换个名字   | 你 Filter 里已经注入的是 `stringRedisTemplate`，改名字反而用不上 |
| 两个 `StringRedisTemplate`Bean 不同名      | Spring 不知道注入哪个，或者你 Filter 里用的还是旧的那个      |
| 改 `RedisTemplate<String, Object>`的序列化 | 那个管的是 `redisTemplate`，**不管 `stringRedisTemplate`**   |

------

## 一句话

> **就加那一个 `StringRedisTemplate`Bean，覆盖自动配置的那个，完事。**

加完 → 重启 tenant → 重新登录 → `token_version`能读到了 → 401 消失。
