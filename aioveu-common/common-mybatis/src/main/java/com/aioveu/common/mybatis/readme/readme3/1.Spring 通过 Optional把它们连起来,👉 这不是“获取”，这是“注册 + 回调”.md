## 二、你现在这套的“正确链路”（非常关键）

### ✅ 1️⃣ 你在 resource 里注册 Bean

```java
// security-resource
@Configuration
public class ResourceSecurityConfig {

    @Bean
    @ConditionalOnMissingBean(DataPermissionHandler.class)
    public DataPermissionHandler dataPermissionHandler() {
        return new MyDataPermissionHandler();
    }
}
```

✅ Bean 定义在 resource
✅ 编译期只依赖 MP 接口

### ✅ 2️⃣ Spring 把 Bean 放进容器

```text
└── DataPermissionHandler (MyDataPermissionHandler)
```

### ✅ 3️⃣ MybatisPlusConfig 只是“问一句”

```java

```

### ✅ 4️⃣ Spring 把 Bean 注入进去
