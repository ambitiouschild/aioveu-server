DIP（依赖倒置原则）是 Java 面向对象设计中 SOLID 原则的第五项，核心要求：‌**高层模块不应依赖低层模块，二者都应依赖抽象；抽象不应依赖细节，细节应依赖抽象**‌。‌‌

### 核心定义与 Java 体现

- ‌**两条准则**‌：① 高层业务逻辑不直接依赖具体实现（如数据库、邮件发送类）；② 所有模块通过接口或抽象类交互，具体实现类依赖抽象而非反之。
- ‌**Java 抽象载体**‌：`interface`（接口）或 `abstract class`（抽象类），禁止高层类直接 `new` 低层具体类。
- ‌**关键目的**‌：解耦模块、提升可测试性（便于 Mock）、支持扩展（符合开闭原则）。‌‌
