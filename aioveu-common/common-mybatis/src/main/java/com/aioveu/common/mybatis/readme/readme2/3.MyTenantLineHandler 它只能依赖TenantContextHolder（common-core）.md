## 一、先给你**最终正确版代码**（直接替换）

```java
package com.aioveu.common.mybatis.handler;

import com.aioveu.common.core.tenant.TenantContextHolder;
import com.aioveu.common.mybatis.properties.TenantMybatisProperties;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import net.sf.jsqlparser.expression.Expression;
import net.sf.jsqlparser.expression.LongValue;
import org.springframework.stereotype.Component;

import java.util.Set;

/**
 * MyBatis-Plus 多租户处理器（基础设施层）
 * <p>
 * 原则：
 * 1. 只消费 TenantContextHolder，不解析 JWT
 * 2. 不依赖 security-resource
 * 3. 特殊表忽略规则通过配置驱动
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class MyTenantLineHandler implements com.baomidou.mybatisplus.extension.plugins.handler.TenantLineHandler {

    private final TenantMybatisProperties tenantProperties;

    @Override
    public Expression getTenantId() {
        Long tenantId = TenantContextHolder.getTenantId();
        log.debug("【MyTenantLineHandler】tenantId from context: {}", tenantId);

        // null：不拼接租户条件（由 ignoreTable 控制）
        if (tenantId == null) {
            return null;
        }

        // 0：平台级（超管），由 ignoreTable 决定是否过滤
        // 这里直接返回 null，让 ignoreTable 接管
        if (tenantId == 0L) {
            return null;
        }

        return new LongValue(tenantId);
    }

    @Override
    public String getTenantIdColumn() {
        return tenantProperties.getColumn();
    }

    @Override
    public boolean ignoreTable(String tableName) {
        if (tableName == null) {
            return false;
        }

        String table = tableName.toLowerCase();

        // 1. 显式配置的忽略表（推荐）
        Set<String> ignoreTables = tenantProperties.getIgnoreTables();
        if (ignoreTables != null && ignoreTables.stream().anyMatch(t -> t.equalsIgnoreCase(table))) {
            log.debug("【MyTenantLineHandler】忽略表(配置): {}", tableName);
            return true;
        }

        // 2. 全局忽略开关（由上层设置）
        if (TenantContextHolder.isIgnoreTenant()) {
            log.debug("【MyTenantLineHandler】全局忽略租户过滤");
            return true;
        }

        return false;
    }
}
```

## 三、**为什么必须这么改（逐条对质你原来的代码）**

### ❌ 1️⃣ `JwtSecurityUtils.getTenantId()`

> 这是你当前最大的一条红线

• `JwtSecurityUtils` ∈ `security-resource`

• `MyTenantLineHandler` ∈ `common-mybatis`


👉 DAO 层反向依赖应用层

✅ 正确做法：
• JWT → Filter → `TenantContextHolder.setTenantId()`

• MP 插件 → `TenantContextHolder.getTenantId()`


---

### ❌ 2️⃣ `TenantProperties`（security-resource 的）

你原来用的是：

```java
com.aioveu.common.security.resource.config.property.TenantProperties
```

👉 这是“安全配置”，不是“MyBatis 配置”

✅ 正确做法：
• MyBatis 用自己的 `TenantMybatisProperties`

• prefix：`mybatis.tenant`


---

### ❌ 3️⃣ `ignoreTable()` 里的“登录场景”逻辑

```java
if (tenantId == null) {
    // sys_user / sys_tenant ...
```

👉 这是“业务语义”，不是“SQL 插件语义”

✅ 正确做法：

• 调用前：`TenantContextHolder.setIgnoreTenant(true)`

• MP 插件只负责：`isIgnoreTenant() → true`

```java

```

👉 MyBatis 插件不该碰数据库元数据

✅ 全部删掉
