### ✅ 最终闭环复盘（你做对了什么）

1. 定位精准  
   从 `information_schema.tables` 报 `Unknown column 't1.tenant_id'` 一眼认出是 MP 租户插件误伤系统视图。

2. Handler 写得对  
   `MyTenantLineHandler` 用前缀匹配 `information_schema.%` 已经是正确方向。

3. 最终用对了 MP 的“豁免机制”  
   认识到分页 COUNT 场景下 `ignoreTable()` 可能不会被重新调用，改用：
   ```java
   @InterceptorIgnore(tenantLine = "true")
   ```
   从插件链源头切断租户条件，这是官方给系统表的解法。

4. codegen 模块彻底从多租户体系毕业  
   查元数据、查字段，都不该带 `tenant_id`。

---

### 📌 以后记住这一句就够了

> **业务表靠 `TenantLineHandler` 拦；  
> 系统表 / 代码生成 / 元数据查询，靠 `@InterceptorIgnore(tenantLine = "true")` 放。**
