## 二、⚠️ 必须改的 3 个点（很重要）

---

### ❌ 1️⃣ `TenantProperties` 的包名仍然“语义不对”

你现在用的是：

```java
import com.aioveu.common.mybatis.config.property.TenantProperties;
```

但从平台语义上看：

| 配置                  | 正确 prefix       |
| --------------------- | ----------------- |
| MyBatis 插件配置      | `mybatis.tenant`  |
| Security 租户解析配置 | `security.tenant` |

👉 它不应该叫 `TenantProperties`
👉 会和 `security.tenant` 的配置类撞车

### ✅ 强烈建议改名

```java
package com.aioveu.common.mybatis.properties;

@ConfigurationProperties(prefix = "mybatis.tenant")
public class TenantMybatisProperties {
    private String column = "tenant_id";
    private Set<String> ignoreTables;
}
```

📌 这是最后一次“命名治理”，否则半年后你会骂自己

---

### ❌ 2️⃣ `ignoreTables` 没有默认值（有风险）

你现在：

```java
List<String> ignoreTables = tenantProperties.getIgnoreTables();
if (ignoreTables == null || ignoreTables.isEmpty()) {
    return false;
}
```

👉 如果没有配置，系统表会被误过滤

### ✅ 正确做法：给“系统表”一个默认兜底

```java
private static final Set<String> DEFAULT_IGNORE_TABLES = Set.of(
    "sys_tenant",
    "sys_user",
    "sys_role",
    "sys_menu",
    "pay_config_wechat",
    "pay_config_alipay",
    "ums_member"
);

@Override
public boolean ignoreTable(String tableName) {
    if (tableName == null) return false;

    if (TenantContextHolder.isIgnoreTenant()) {
        return true;
    }

    Set<String> ignores = tenantProperties.getIgnoreTables();
    if (ignores == null || ignores.isEmpty()) {
        ignores = DEFAULT_IGNORE_TABLES;
    }

    return ignores.stream()
            .anyMatch(t -> t.equalsIgnoreCase(tableName));
}
```

✅ 即使配置忘了写，系统也不会炸

---

### ❌ 3️⃣ `@Component` + `@PostConstruct` 是“软依赖”

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class MyTenantLineHandler implements TenantLineHandler
```

👉 这个 Bean 不应该由组件扫描决定
👉 应该由 `MybatisPlusConfig` 显式创建

### ✅ 推荐写法（平台级）

```java
// 去掉 @Component / @PostConstruct
@Slf4j
@RequiredArgsConstructor
public class MyTenantLineHandler implements TenantLineHandler {

    private final TenantMybatisProperties tenantProperties;
}
```

```java
@Configuration
public class MybatisPlusConfig {

    @Bean
    @ConditionalOnMissingBean
    public TenantLineHandler tenantLineHandler(
            TenantMybatisProperties properties) {
        log.info("=== MyTenantLineHandler 注册 ===");
        return new MyTenantLineHandler(properties);
    }
}
```

✅ 启动顺序可控
✅ 自动装配语义清晰
✅ 不会被“误扫描”
