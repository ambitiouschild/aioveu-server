# 一、你现在卡住的本质原因

你把问题理解成了：

> ❌ “`sys_user` 什么时候该被过滤？”

但主流架构的思考方式是：

> ✅ “当前请求处于什么阶段？”

---

# 二、主流多租户系统的「请求生命周期」（重点）

```
① 登录前（无 Token）
   └── 平台接口
       └── 查用户名是否存在
       └── 查用户有哪些租户
       └── ❌ 不拼 tenant_id
       └── ✅ 直接查 sys_user

② 登录中（认证）
   └── Spring Security / OAuth2
   └── 生成 JWT（写入 tenant_id）

③ 登录后（有 Token）
   └── 业务接口
       └── 所有 SQL
       └── ✅ MP 自动拼 tenant_id
       └── ✅ sys_user 也必须过滤
```

👉 同一个 `sys_user` 表，在不同阶段，规则完全不同

---

# 三、主流方案（99% 大厂都在用）

## ✅✅✅ 方案 A：**登录链路完全独立（最主流）**

### 核心思想

> 登录接口 ≠ 业务接口
>
> 登录接口不走 MP 多租户

---

### 1️⃣ 登录接口（平台级）

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    @PostMapping("/tenants/{username}")
    public Result<List<TenantVO>> getTenants(
            @PathVariable String username
    ) {
        // ✅ 手写 SQL / View
        // ✅ 不依赖 MP
        return Result.success(userService.getTenantsByUsername(username));
    }
}
```

#### Mapper（关键）

```java
@Select("""
    SELECT t.id, t.name
    FROM sys_user u
    JOIN sys_tenant t ON u.tenant_id = t.id
    WHERE u.username = #{username}
      AND u.is_deleted = 0
""")
List<TenantVO> getTenantsByUsername(String username);
```

✅ 不拼 tenant_id
✅ 不进 MP
✅ 不碰 TenantContextHolder

---

### 2️⃣ 登录接口（认证）

```java
@PostMapping("/login")
public Result<?> login(@RequestBody LoginDTO dto) {
    // 校验 username + password + tenantId
}
```

✅ tenantId 由前端选择
✅ 后端只校验

---

### 3️⃣ 登录后业务接口（MP 全自动）

```java
this.list(
    new LambdaQueryWrapper<User>()
        .eq(User::getStatus, 1)
);
```

MP 自动拼：

```sql
AND tenant_id = ?
```

✅ 无需你关心
✅ 不会越权
✅ 安全

## 四、为什么这个方案是“主流”？

### ✅ 优点

| 维度     | 说明                |
| -------- | ------------------- |
| 安全性   | 登录 / 业务完全隔离 |
| 可维护性 | 不写奇葩 if         |
| 可扩展性 | 支持多租户登录      |
| 面试加分 | 架构师级设计        |
| 框架兼容 | MP 官方推荐思路     |

### ❌ 不这么做会怎样？

• 登录接口和业务接口逻辑混在一起

• `ignoreTable()` 里一堆 `if (login)`

• 新人一看就懵

• 越权漏洞高发区

# 六、如果你一定要“优雅一点”的主流变种（推荐）

### ✅ 增加一个「平台接口标记」

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface PlatformApi {
}
```

```java
@PlatformApi
@GetMapping("/tenants/{username}")
public Result<?> getTenants() { ... }
```

### ✅ Interceptor 中标记

```java
if (handlerMethod.hasMethodAnnotation(PlatformApi.class)) {
    TenantContextHolder.markIgnore();
}
```

✅ 语义清晰
✅ 不影响 MP
✅ 可审计
✅ 大厂常用
