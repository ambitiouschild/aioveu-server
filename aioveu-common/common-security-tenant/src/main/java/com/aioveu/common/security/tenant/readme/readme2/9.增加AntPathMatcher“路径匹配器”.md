## 一、先给你一个“确定答案”

> ✅ **加了 `AntPathMatcher`，`\**`一定可以用**
>
> ⚠️ **`{username}`虽然“能匹配”，但不推荐、不优雅、不专业**

------

## 二、`AntPathMatcher`到底解决了什么？

### 没有它（你现在）

```
uri.startsWith("/aioveu/api/v8/admin/tenant/users/tenants/**")
```

👉 JVM 眼里这是**纯字符串**

👉 `**`= 普通字符

👉 永远 `false`

------

### 有了它（正确）

```
antPathMatcher.match(
    "/aioveu/api/v8/admin/tenant/users/tenants/**",
    "/aioveu/api/v8/admin/tenant/users/tenants/xinhuan"
)
```

👉 Spring 会：

- 

  解析 `**`

- 

  解析 `*`

- 

  解析 `{username}`

- 

  做真正的路径匹配

✅ **这才是“路径匹配器”**

------

## 三、`{username}`真的“能用”吗？（重点）

### ✅ 技术上：能用

```
antPathMatcher.match(
    "/aioveu/api/v8/admin/tenant/users/tenants/{username}",
    "/aioveu/api/v8/admin/tenant/users/tenants/xinhuan"
)
```

👉 **返回 `true`**

------

### ❌ 工程上：不推荐（原因很硬）

#### 1️⃣ `{username}`是 **Spring MVC 的语义**

它存在的意义是：

```
@GetMapping("/tenants/{username}")
public User getUser(@PathVariable String username)
```

👉 **用来“取值”，不是用来“判断权限 / 放行”**

------

#### 2️⃣ 白名单里写 `{username}`会误导人

下一个接手的人会以为：

> “哦？这里也支持 MVC 占位符？”

然后他：

- 

  去查 Controller

- 

  去对齐路径

- 

  最后发现：**完全是两套机制**

------

#### 3️⃣ 以后一定会出“误删事故”

比如有人重构：

```
# 旧
- /tenants/{username}

# 新（看起来等价，实际不等价）
- /tenants/**
```

或者直接删掉 `{username}`，以为没用。

------

## 四、我的“终局建议”（你可以直接照抄）

### ✅ 白名单（Filter / Gateway / Security）

```
common:
  security:
    tenant:
      whitelist-paths:
        - /aioveu/api/v8/admin/tenant/users/tenants/**
```

### ✅ Controller（语义 & 参数）

```
@GetMapping("/tenants/{username}")
public Result<?> getUserTenants(@PathVariable String username) {
    ...
}
```

### ✅ Filter 代码（最终版）

```
private static final AntPathMatcher antPathMatcher = new AntPathMatcher();

@Override
protected boolean shouldNotFilter(HttpServletRequest request) {
    String uri = request.getRequestURI();

    String auth = request.getHeader(HttpHeaders.AUTHORIZATION);
    if (StringUtils.hasText(auth) && auth.startsWith("Bearer ")) {
        return true;
    }

    List<String> whitelist = tenantResolveProperties.getWhitelistPaths();
    if (CollectionUtil.isEmpty(whitelist)) {
        return true;
    }

    boolean isWhitelist = whitelist.stream()
            .anyMatch(pattern -> antPathMatcher.match(pattern, uri));

    log.info("【PublicTenantFilter】URI={}, isWhitelist={}", uri, isWhitelist);
    return !isWhitelist;
}
```
