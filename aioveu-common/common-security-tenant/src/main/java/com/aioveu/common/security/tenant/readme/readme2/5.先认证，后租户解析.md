## 五、一个非常重要的“认知升级”

> “先认证” ≠ “一定要有 JWT”
>
> “先认证” = “认证层先做出决策”

决策有三种结果：

| 结果              | 行为                        |
| ----------------- | --------------------------- |
| 有 JWT            | 认证成功，tenantId 来自 JWT |
| 无 JWT + 白名单   | 认证放行，租户解析介入      |
| 无 JWT + 非白名单 | 拒绝访问                    |

👉 顺序永远是：认证先表态
👉 租户解析只是“后续执行策略”
