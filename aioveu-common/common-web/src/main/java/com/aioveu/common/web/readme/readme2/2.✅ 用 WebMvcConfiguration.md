## 一、一句话结论（先给）

> ✅ 推荐：`WebMvcConfiguration`
>
> ✅ 理由：这是 Spring / Spring Boot 官方风格
>
> ⚠️ `WebMvcConfig` 也不是错，但不够“官方”

---

## 二、Spring 官方 / Spring Boot 的真实习惯

你去翻 Spring Boot 源码，你会发现：

| 官方类名                  | 出现频率   |
| ------------------------- | ---------- |
| `WebMvcConfiguration`     | ✅✅✅✅✅      |
| `SecurityConfiguration`   | ✅✅✅✅✅      |
| `JacksonConfiguration`    | ✅✅✅✅✅      |
| `DataSourceConfiguration` | ✅✅✅✅✅      |
| `WebMvcConfig`            | ❌ 极少     |
| `MvcConfig`               | ❌ 几乎没有 |

👉 Spring 官方偏好：
> `<Feature> + Configuration`

---

## 三、为什么 `WebMvcConfiguration` 更好？

### ✅ 1️⃣ 语义更完整

| 命名                  | 给人的感觉                     |
| --------------------- | ------------------------------ |
| `WebMvcConfiguration` | “这是 WebMVC 的配置类”         |
| `WebMvcConfig`        | “这是一个配置，顺便配一下 MVC” |

👉 Configuration 是名词，Config 更像动词

---

### ✅ 2️⃣ 和 Spring 生态一致性最好

你现在的项目里大概率已经有：

```java
SecurityConfiguration
MybatisConfiguration
RedisConfiguration
TenantConfiguration
```

✅ `WebMvcConfiguration` 天然对齐

---

### ✅ 3️⃣ 对“框架级代码”更友好

你现在写的是：

• 拦截器

• 跨模块 Common

• 多租户基础设施


👉 这是“框架级配置”，不是“临时配置”

`Configuration` 更符合这个身份。

---

## 四、什么时候可以用 `WebMvcConfig`？

✅ 可以用，但只适合以下场景：

• 单体小项目

• Demo / PoC

• 个人项目

• 非公共模块


❌ 不适合：
• Common 模块

• Starter

• 多模块架构

• 团队规范项目


---

## 五、我给你一个“命名决策表”（直接当规范）

| 场景              | 推荐命名                  |
| ----------------- | ------------------------- |
| Spring MVC 配置   | ✅ `WebMvcConfiguration`   |
| Security 配置     | ✅ `SecurityConfiguration` |
| MyBatis / MP 配置 | ✅ `MybatisConfiguration`  |
| Redis 配置        | ✅ `RedisConfiguration`    |
| Jackson 配置      | ✅ `JacksonConfiguration`  |
| 简单属性配置      | ✅ `XxxProperties`         |
| 配置聚合类        | ✅ `XxxAutoConfiguration`  |
| 非 Spring 配置类  | ✅ `XxxConfig`（如 POJO）  |

## 六、你这个项目的最终推荐 ✅

```java
package com.aioveu.common.web.config;

@Configuration
public class WebMvcConfiguration implements WebMvcConfigurer {
    ...
}
```

✅ 语义正确
✅ 官方风格
✅ 团队友好
✅ 长期可维护

## 七、一个“架构师级”的小细节（加分）

如果你以后打算做成 starter，可以进一步升级：

```java
@AutoConfiguration
@ConditionalOnWebApplication(type = Type.SERVLET)
public class WebMvcAutoConfiguration implements WebMvcConfigurer {
}
```

👉 这就是 Spring Boot Starter 的写法
👉 你现在这套，已经离 starter 只差一步
