### ✅ 具体做法（两种，二选一）

------

### ✅✅ 方案 A（强烈推荐）：Job 彻底关闭租户插件

```
@Scheduled(cron = "0 */5 * * * ?")
public void reconcile() {
    InterceptorIgnoreHelper.handle(
        IgnoreStrategy.builder()
            .tenantLine(true)
            .build()
    );

    try {
        // 全量查 pay_order
    } finally {
        InterceptorIgnoreHelper.clearIgnoreStrategy();
    }
}
```

✅ Job 线程里：

- 

  没有租户

- 

  不串号

- 

  不乱查

- 

  不污染

👉 **这是“多租户系统”里最成熟的 Job 写法**

### ✅✅ 方案 B（架构级）：Job 独立数据源 / 独立 Mapper

- 

  Job 用**非租户 Mapper**

- 

  Web 用**租户 Mapper**

- 

  物理隔离，语义最清

✅ 银行 / 支付 / 账务系统常用

❌ 成本高，你目前没必要
