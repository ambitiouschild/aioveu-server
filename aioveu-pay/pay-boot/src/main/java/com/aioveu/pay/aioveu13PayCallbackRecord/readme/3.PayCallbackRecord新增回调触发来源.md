对，强烈建议加一个 `source` 字段。你现在不就已经在代码里用 `source = "POLLING"` / `"WECHAT_CALLBACK"` 来区分了吗？不落库的话以后排查问题全是瞎子。

---

## 为什么一定要加

| 场景                                     | 没 source 字段                     | 有 source 字段                                               |
| ---------------------------------------- | ---------------------------------- | ------------------------------------------------------------ |
| 运营问"这笔为什么没收到 OMS 通知"        | 翻代码猜是轮询还是回调触发的       | 直接 `SELECT source FROM pay_callback_record WHERE payment_no = ?` |
| 对账时发现重复处理                       | 不知道是微信推了两次还是轮询扫到了 | source 一看就知道                                            |
| 统计各来源成功率                         | 做不到                             | `GROUP BY source` 一行 SQL                                   |
| 以后加新的触发方式（Job 补单、手动重试） | 又是一坨 if-else 猜来源            | 统一加个枚举值就完事                                         |

## 怎么加

### 1️⃣ 加字段（DB）

```sql
ALTER TABLE pay_callback_record 
ADD COLUMN source VARCHAR(20) NOT NULL DEFAULT 'UNKNOWN' 
COMMENT '触发来源: WECHAT_CALLBACK / POLLING / MANUAL / JOB_RETRY' 
AFTER channel;
```

### 2️⃣ 加枚举（代码）

```java
package com.aioveu.common.enums.pay;

public enum CallbackSourceEnum {
    WECHAT_CALLBACK("WECHAT_CALLBACK", "微信回调"),
    POLLING("POLLING", "轮询"),
    MANUAL("MANUAL", "人工发送"),
    JOB_RETRY("JOB_RETRY", "Job定时重试");

    private final String code;
    private final String desc;

    CallbackSourceEnum(String code, String desc) {
        this.code = code;
        this.desc = desc;
    }

    public String getCode() { return code; }
    public String getDesc() { return desc; }
}
```

### 3️⃣ 实体加字段

```java
/**
 * 触发来源：WECHAT_CALLBACK / POLLING / MANUAL / JOB_RETRY
 */
private String source;
```

### 4️⃣ `saveCallbackRecord` 里 set 进去

你之前统一的那个方法改一行：


## 顺便：你这个实体还有几个小问题顺手提一下

| 问题                                          | 说明                                                         |
| --------------------------------------------- | ------------------------------------------------------------ |
| `tenantId` 重复声明                           | 你继承了 `BaseEntityWithTenantId`，父类里应该已经有了，子类再声明会覆盖父类的字段，导致 MP 映射混乱。检查一下父类，如果有就删掉这行 |
| `isDeleted` 重复声明                          | 同上，父类 `BaseEntity` 一般已经有 `isDeleted` 了            |
| `notifyStatus` 用枚举 ✅                       | 很好，保持                                                   |
| `paidAmount` 字段有但你的 INSERT SQL 里没 set | 看日志里 INSERT 没有 `paid_amount` 列——要么补 set，要么 DB 给默认值 |
