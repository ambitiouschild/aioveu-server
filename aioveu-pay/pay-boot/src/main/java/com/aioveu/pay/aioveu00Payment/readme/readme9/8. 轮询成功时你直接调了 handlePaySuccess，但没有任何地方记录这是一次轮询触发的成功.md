```
private void saveCallbackRecord(String paymentNo, String transactionId, LocalDateTime paidTime, Object rawParams, String source) {
    
    PayOrder payOrder = payOrderService.getByPaymentNo(paymentNo);
    if (payOrder == null) return;

    // 幂等：如果已经有一条相同 transactionId + source 的记录，跳过
    if (StringUtils.hasText(transactionId) 
            && payCallbackRecordService.isConsumed(transactionId)) {
        log.info("【回调记录】已存在，跳过: transactionId={}", transactionId);
        return;
    }

    PayCallbackRecord record = PayCallbackRecord.builder()
            .paymentNo(paymentNo)
            .orderNo(payOrder.getOrderNo())
            .transactionId(transactionId)
            .channel(source.contains("WECHAT") ? "WECHAT" : "POLLING")
            .callbackStatus(PaymentCallbackStatusEnum.SUCCESS)
            .rawData(rawParams != null ? JSON.toJSONString(rawParams) : null)
            .paidTime(paidTime)
            .notifyCount(1)
            .build();

    payCallbackRecordService.save(record);
    log.info("【回调记录】已保存: paymentNo={}, source={}", paymentNo, source);
}
```

## 顺手帮你发现一个你代码里的小问题

你在 `queryPaymentStatusByPaymentNo`里这段：

```
//微信查询 → 视同"回调"
payOrderService.updateById(update);
```

**这里还在用 `updateById(update)`直接更新！** 你之前加了乐观锁之后，这里没改。虽然 `update`里只 set 了 `paymentStatus`、`thirdTransactionNo`、`paymentTime`，version 靠 MP 自动处理——**但这里没设 version 旧值，乐观锁会生效吗？**

看你 `update`对象：

```
PayOrder update = new PayOrder();
update.setId(payOrder.getId());
update.setPaymentStatus(...);
update.setThirdTransactionNo(...);
update.setPaymentTime(...);
// ⚠️ version 没设！
```

**MP 的乐观锁插件要求 entity 里必须有 version 的旧值。** 你这里是 new 了一个空对象只设了 id，version 是 null → 插件不会拼 `AND version = ?`→ **实际上没走乐观锁**。

要改成：

```
// ✅ 直接从查出来的 payOrder 上改，version 有值
payOrder.setPaymentStatus(wxResult.getPaymentStatus());
payOrder.setThirdTransactionNo(wxResult.getThirdPaymentNo());
if (wxResult.getPaymentStatus() == PaymentStatusEnum.PAID) {
    payOrder.setPaymentTime(wxResult.getPaymentTime());
}
payOrderService.updateById(payOrder); // ✅ version 有值，乐观锁生效
```
