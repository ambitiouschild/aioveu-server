## 二、你刚才那句话，逐字拆开都是对的

### ✅ 1️⃣「登录请求访问 auth，触发了 MP」

```
POST /oauth/token
↓
auth 服务
↓
TenantFilter.setTenantId()
↓
UserDetailsService.loadUserByUsername()
↓
MP TenantLineHandler 生效 ✅
```

✅ **这是在 auth 自己的 JVM 里**

✅ **ThreadLocal 有值**

✅ **MP 当然能拼 `tenant_id`**

------

### ✅ 2️⃣「loadUserByUsername 调用 tenant 的 Feign」

```
UserDetailsService
↓
tenantFeignClient.getUserAuthCredentialsByUsernameAndTenantId()
↓
HTTP 调用 tenant 服务
```

⚠️ **重点来了：**

- 

  这是 **HTTP**

- 

  不是方法调用

- 

  ThreadLocal **不会跟着过来**

------

### ✅ 3️⃣「tenant 没有触发 MP」

在 tenant 服务里：

```
TenantFilter
  ↓
检测到 JWT / 白名单
  ↓
shouldNotFilter = true
  ↓
skip
  ↓
TenantContextHolder = null
  ↓
MP TenantLineHandler：
    getTenantId() → null
  ↓
SQL 不拼 tenant_id
```

✅ **MP 不是没“能力”**

✅ **是 tenant 服务里“前提条件”不存在**
