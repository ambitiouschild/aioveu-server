## ✅ 五、租户切换要不要写 token_version？（重要）

### ✅ 建议：**租户切换也写**

否则会出现：

• JWT 里 token_version = 99

• Redis 里 version = 100

• 一访问 → 被踢


### ✅ 租户切换里补一刀

```java
private Authentication authenticateForTenantSwitch(String username, String tenantId) {

    UserDetails userDetails = sysUserDetailsService.loadUserByUsername(username);

    if (userDetails instanceof SysUserDetails sysUserDetails) {
        sysUserDetails.setTenantId(Long.valueOf(tenantId));

        // ✅ 租户切换也递增 token_version
        String versionKey = RedisConstants.Auth.USER_TOKEN_VERSION + sysUserDetails.getUserId();
        Long tokenVersion = stringRedisTemplate.opsForValue().increment(versionKey);
        sysUserDetails.setTokenVersion(tokenVersion);

        log.info("【TokenVersion】租户切换，用户 {}，新 token_version = {}",
                sysUserDetails.getUserId(), tokenVersion);
    }

    return new UsernamePasswordAuthenticationToken(
            userDetails,
            null,
            userDetails.getAuthorities()
    );
}
```

✅ 租户切换 = 新 token = 新版本
✅ 旧 token 自动失效
