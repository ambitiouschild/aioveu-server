## 二、关键知识点（你这一步刚好踩在“分界线上”）

### ✅ `DelegatingPasswordEncoder` 的工作规则

它会根据密码的 前缀 选择编码器：

| 密码前缀   | 使用的编码器            |
| ---------- | ----------------------- |
| `{bcrypt}` | `BCryptPasswordEncoder` |
| `{noop}`   | 明文                    |
| `{pbkdf2}` | Pbkdf2                  |
| 无前缀     | ❌ 无法识别              |

---

### ✅ 你现在数据库里是这样：

```
$2a$10$xVWsNohHrCxh5...
```

### ❌ 但 `DelegatingPasswordEncoder` 期望的是：

```
{bcrypt}$2a$10$xVWsNohHrCxh5...
```

👉 少了一截 `{bcrypt}`
👉 Spring Security 5+ 直接判定：无法识别编码格式
👉 密码比对失败
👉 然后它“甩锅”给了 `LockedException`（这是 Spring 的历史包袱 Bug）
