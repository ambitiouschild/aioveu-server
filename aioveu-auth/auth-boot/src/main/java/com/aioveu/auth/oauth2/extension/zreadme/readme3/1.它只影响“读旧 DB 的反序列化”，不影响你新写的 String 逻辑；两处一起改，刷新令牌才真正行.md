## 三、直接可复制的完整 Bean（你之前说保留旧 DB → 用这个）

```
package com.aioveu.auth.config;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.jsontype.BasicPolymorphicTypeValidator;
import com.fasterxml.jackson.databind.jsontype.PolymorphicTypeValidator;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.jackson2.SecurityJackson2Modules;

@Configuration
public class AuthorizationServerConfig {

    @Bean
    public ObjectMapper objectMapper() {
        ObjectMapper mapper = new ObjectMapper();

        // ✅ 放行 Jackson 类型反序列化（允许 Long 等）
        PolymorphicTypeValidator validator =
                BasicPolymorphicTypeValidator.builder()
                        .allowIfBaseType(Object.class)
                        .build();

        mapper.activateDefaultTyping(
                validator,
                ObjectMapper.DefaultTyping.NON_FINAL
        );

        // ✅ 注册 Spring Security 的 Jackson 模块（必须）
        mapper.registerModules(
                SecurityJackson2Modules.getModules(getClass().getClassLoader())
        );

        return mapper;
    }
}
```

✅ 旧 `Long`能反序列化

✅ refresh_token 立刻不炸

❌ 安全边界放开（你选保留，就必须接受）
