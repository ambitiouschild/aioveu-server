## 三、为什么“按钮不显示”是最明显的症状？

因为：

| 阶段     | 状态               |
| -------- | ------------------ |
| 登录     | ✅ 成功（蒙混过关） |
| 用户信息 | ❌ 租户错误         |
| 角色     | ❌ 错的             |
| 菜单     | ❌ 租户不匹配       |
| 按钮权限 | ❌ 直接为空         |
| 前端     | ✅ 按钮消失         |

👉 系统“看起来能登录”
👉 但权限全线崩盘

这是 最阴险的一类多租户 Bug。
