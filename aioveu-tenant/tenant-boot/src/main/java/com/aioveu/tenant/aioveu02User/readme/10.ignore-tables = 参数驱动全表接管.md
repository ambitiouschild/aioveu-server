## 二、为什么“必须全部换成参数驱动”？

因为：

### 一旦 ignore：

```
ignore-tables:
  - sys_user
```

👉 **MP 立刻、永久、无条件地：**

- 

  ❌ 不再自动拼接 `tenant_id`

- 

  ❌ 不再替换 `tenant_id`

- 

  ❌ 不再读取 `TenantContextHolder`

- 

  ❌ 不再管你是不是登录、是不是后台、是不是定时任务

**这张表，在 MP 眼里，从此“没有租户”**

## 三、会发生什么，如果你“只改一半”

👉 **结果：**

- 

  登录安全 ✅

- 

  用户列表：**查出所有租户的用户** 🚨

- 

  编辑 / 删除：**跨租户操作** 🚨

👉 **这是灾难级 Bug**

## 四、“全部接口换成参数驱动”的真实含义

不是“我觉得参数驱动”，而是：

### ✅ SQL 里必须出现 `tenant_id`

```
AND sys_user.tenant_id = #{tenantId}
```

### ✅ Wrapper 里必须手写

```
wrapper.eq("tenant_id", tenantId);
```

### ✅ 所有入口都必须传

- 

  Controller

- 

  Service

- 

  Mapper

- 

  定时任务

- 

  事件监听

- 

  内部 RPC

👉 **少一个，就是漏洞**
