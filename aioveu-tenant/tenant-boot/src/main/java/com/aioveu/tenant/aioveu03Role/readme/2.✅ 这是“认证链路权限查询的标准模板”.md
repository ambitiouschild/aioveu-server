## ✅ 一、最严重的问题（必须改，否则运行期翻车）

### ❌ 1️⃣ `resultType="RolePermMap"` 是**非法用法**

```xml
<select id="listRolePermsGroupByRoleWithTenantId"
        resultType="RolePermMap">
```

👉 MyBatis 不允许 `resultType` 指向 `resultMap`

| 属性         | 用途                       |
| ------------ | -------------------------- |
| `resultType` | 返回简单类型 / POJO        |
| `resultMap`  | 返回复杂映射（collection） |

✅ 正确写法：

```xml
<select id="listRolePermsGroupByRoleWithTenantId"
        resultMap="RolePermMap">
```

⚠️ 这个不改，启动必炸或运行结果不可预测

---

### ❌ 2️⃣ `@MapKey` 在 Java Mapper 里**必须存在**

XML 对了没用，接口不对等于白写。

✅ 正确 Mapper 方法：

```java
/**
 * 按角色分组查询按钮权限（认证链路专用）
 */
@MapKey("roleCode")
Map<String, Set<String>> listRolePermsGroupByRoleWithTenantId(
        @Param("params") Map<String, Object> params
);
```

👉 没有 `@MapKey("roleCode")`：
• MyBatis 不知道谁是 key

• 返回类型混乱

• Service 里直接崩


---

### ❌ 3️⃣ `HashMap` 作为 `resultMap type` 是**不规范的**

```xml
<resultMap id="RolePermMap" type="java.util.HashMap">
```

虽然 能跑，但有两个问题：

• ❌ MyBatis 官方不推荐

• ❌ 后续维护者看不懂

• ❌ IDE / 编译器无法校验


✅ 推荐写法：建一个 BO

```java
@Data
public class RolePermMapBO {
    private String roleCode;
    private Set<String> perms = new HashSet<>();
}
```

```xml
<resultMap id="RolePermMap" type="com.xxx.RolePermMapBO">
    <id property="roleCode" column="roleCode"/>
    <collection property="perms"
                ofType="java.lang.String"
                javaType="java.util.HashSet">
        <result column="perm"/>
    </collection>
</resultMap>
```

✅ 这是“生产级标准写法”

## ✅ 二、一个“高危安全隐患”（必须改）

### ❌ 4️⃣ 仍在大量使用 `${}` 枚举（SQL 注入风险）

```xml
${@com.aioveu.tenant.aioveu04Menu.enums.MenuTypeEnum@BUTTON.getValue()}
```

❌ OGNL
❌ 非预编译
❌ 不符合你现在的“参数驱动”哲学

✅ 必须统一改成：

```xml
AND t2.type = #{buttonType}
```

Mapper：

```java
@Param("buttonType") Integer buttonType
```

Service：

```java
params.put("buttonType", MenuTypeEnum.BUTTON.getValue());
```

👉 你后面两条 SQL 是对的，前面两条必须同步改

## ✅ 六、最终“上线级”修正版（精简后）

### ✅ Mapper 接口（生死线）

```java
@MapKey("roleCode")
Map<String, Set<String>> listRolePermsGroupByRoleWithTenantId(
        @Param("params") Map<String, Object> params
);
```

### ✅ XML（最小正确版）

```xml
<resultMap id="RolePermMap" type="com.xxx.RolePermMapBO">
    <id property="roleCode" column="roleCode"/>
    <collection property="perms"
                ofType="java.lang.String"
                javaType="java.util.HashSet">
        <result column="perm"/>
    </collection>
</resultMap>

<select id="listRolePermsGroupByRoleWithTenantId"
        resultMap="RolePermMap">
    SELECT
        t3.code AS roleCode,
        t2.perm AS perm
    FROM sys_role_menu t1
    INNER JOIN sys_menu t2 ON t2.id = t1.menu_id
    INNER JOIN sys_role t3 ON t3.id = t1.role_id
    <where>
        AND t2.type = #{params.buttonType}
        AND t2.perm IS NOT NULL

        AND t3.code IN
        <foreach collection="params" item="role" separator="," open="(" close=")">
            #{role}
        </foreach>

        AND t1.tenant_id = #{params.tenantId}
        AND t2.tenant_id = #{params.tenantId}
        AND t3.tenant_id = #{params.tenantId}

        AND t1.is_deleted = 0
        AND t2.is_deleted = 0
        AND t3.is_deleted = 0
    </where>
</select>
```
