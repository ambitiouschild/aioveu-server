## 三、真正的坑在这里（SaaS 经典雷区）

### ⚠️ 套餐菜单 ≠ 按钮权限

在大多数 RBAC 设计中：

| sys_menu.type | 含义              |
| ------------- | ----------------- |
| C             | 目录              |
| M             | 菜单              |
| F             | **按钮 / 权限点** |

而你的套餐菜单 **极大概率只包含 C + M**：

```
SELECT * FROM sys_menu WHERE id IN (套餐菜单IDs);
-- type IN ('C','M')
```

✅ 所以：

- 

  租户管理员能看到「角色管理」菜单 ✅

- 

  但 **看不到「分配权限」按钮** ❌

- 

  也看不到「新增」「编辑」「删除」按钮 ❌
