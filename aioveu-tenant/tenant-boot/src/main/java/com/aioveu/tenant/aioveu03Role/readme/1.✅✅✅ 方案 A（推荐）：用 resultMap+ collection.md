## ✅ 一、最重要：你这个 Mapper **缺了 `@MapKey` 方法签名**

你现在 XML 是完美的，但 Java Mapper 接口必须对得上，否则运行必炸。

### ❌ 你现在只有 XML，没有对应接口方法

### ✅ 正确 Mapper 接口（必须这样写）

```java
/**
 * 按角色分组查询按钮权限（认证链路专用）
 */
@MapKey("roleCode")
Map<String, Set<String>> listRolePermsGroupByRoleWithTenantId(
        @Param("params") Map<String, Object> params
);
```

⚠️ 没有 `@MapKey("roleCode")`：
• MyBatis 不知道谁是 Map 的 key

• 返回的是 `Map<String, String>` 或乱七八糟的结构


✅ 这是你这套 XML 能否工作的“生死线”

## ✅ 二、一个“隐性 Bug”（非常关键）

### ❌ 问题：`resultType="java.lang.String"` + `@MapKey`

你现在是：

```xml
<select id="listRolePermsGroupByRoleWithTenantId"
        resultType="java.lang.String">
```

但你在 Java 里想要的是：

```java
Map<String, Set<String>>
```

### ❌ MyBatis 会怎样？

• 每一行只有一个 `perm`

• MyBatis 会尝试把 `perm` 当 value

• 但 Set 不会自动聚合

• 实际结果可能是：

  • `Map<String, String>`

  • 或最后一条 perm 覆盖前面的


---

### ✅ 正确写法（二选一）

---

### ✅✅✅ 方案 A（推荐）：用 `resultMap` + `collection`

```xml
<resultMap id="RolePermMap" type="java.util.HashMap">
    <id property="roleCode" column="roleCode"/>
    <collection property="perms"
                ofType="java.lang.String"
                javaType="java.util.HashSet">
        <result column="perm"/>
    </collection>
</resultMap>

<select id="listRolePermsGroupByRoleWithTenantId"
        resultMap="RolePermMap">
    SELECT
        t3.code AS roleCode,
        t2.perm AS perm
    FROM sys_role_menu t1
    INNER JOIN sys_menu t2 ON t2.id = t1.menu_id
    INNER JOIN sys_role t3 ON t3.id = t1.role_id
    <where>
        AND t2.type = #{params.buttonType}
        AND t2.perm IS NOT NULL

        AND t3.code IN
        <foreach collection="params" item="role" separator="," open="(" close=")">
            #{role}
        </foreach>

        AND t1.tenant_id = #{params.tenantId}
        AND t2.tenant_id = #{params.tenantId}
        AND t3.tenant_id = #{params.tenantId}

        AND t1.is_deleted = 0
        AND t2.is_deleted = 0
        AND t3.is_deleted = 0
    </where>
</select>
```

✅ 这是“教科书级”写法
✅ `@MapKey("roleCode")` 才能正确生效
✅ `Set<String>` 自动聚合

---

### ✅ 方案 B（偷懒但能用）：保持 `resultType=String` + `@MapKey`
