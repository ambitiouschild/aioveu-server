## ✅ 护身符一：上线首单「最小验证路径」

只测这 4 步，别贪多：

1. 下一笔 0.01 元的真实支付订单
2. 后台发货

3. 小程序端点「确认收货」

   • 自提：是否直接本地完结 ✅

4. 点完原生确认后
   • 本地是否变成 COMPLETED ✅

   • 微信订单中心是否同步 ✅

## ✅ 护身符二：上线当天日志盯 3 个关键字

后端日志搜：

```
【微信发货】
【微信原生确认收货成功回调】
【confirmReceipt】
```

一旦出现：

• `412 + 空 body` → 忽略，记录日志即可（说明微信侧已存在发货/确认记录）

• `referrerInfo.appId=wx1183b055aeec94d1` → 说明用户真的点了原生确认

• `乐观锁 rows=0` → 说明本地已被处理，幂等生效

## ✅ 护身符三：给产品 / 测试的「一句话说明」

你上线后可以原样发给别人：

> 微信交易组件的确认收货分两种：
> - 快递：必须用户在微信原生组件里点确认，商家端才能同步；
> - 自提 / 虚拟：商家点完即本地完结，微信会在发货后第 2 天自动确认。
>
> 本次上线只验证「快递原生确认 + 自提本地完结」两条链路，资金结算以微信商户平台为准。
