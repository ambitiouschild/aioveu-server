## 关键细节（容易漏的）

### 1️⃣ 不要等 openBusinessView 的 success 回调

很多人写错成这样：

```
// ❌ 错！success 只是"组件成功打开了"，不代表用户点了确认
wx.openBusinessView({
  success(res) {
    confirmReceipt(orderSn) // 用户还没点确认你就改状态了！
  }
})
```

**`success`= 组件弹出来了，用户可能直接划掉。** 必须等 `onShow`里的 `extraData.status === 'success'`才是用户真点了。

### 2️⃣ onShow 里要判断来源 appId

```
// App.vue 或 pages/order/detail.vue 的 onShow
onShow(options) {
  const referrer = options.referrerInfo
  if (referrer?.appId === 'wx1183b055aeec94d1'  // 微信订单组件的 appId
      && referrer.extraData?.status === 'success') {
    // ✅ 用户真的在微信原生组件里点了确认
    this.$api.order.confirmReceipt(this.orderSn)
  }
}
```

### 3️⃣ 后端 confirmReceipt 加一个防重（你已经有了 ✅）

```
// 乐观锁 + 幂等日志，重复调也不怕
if (rows == 0) {
    throw new BusinessException("订单已被处理，请刷新后重试");
}
```

### 4️⃣ 自提/虚拟单不需要拉组件

```
// 订单详情页按钮点击
onConfirmReceipt() {
  if (this.order.logisticsType === 3 || this.order.logisticsType === 2) {
    // 自提/虚拟 → 直接调后端，不拉微信组件
    this.$api.order.confirmReceipt(this.orderSn)
  } else {
    // 快递 → 拉微信原生组件
    wx.openBusinessView({ ... })
  }
}
```
