## 二、关键字段逐一解释（避坑指南）

| 字段                                       | 类型   | 必填       | 说明 & 坑点                                                  |
| ------------------------------------------ | ------ | ---------- | ------------------------------------------------------------ |
| `order_key.order_number_type`              | int    | ✅          | `1`=商户单号 `2`=微信支付单号。**你用的是 transaction_id，所以必须是 `2`** |
| `order_key.transaction_id`                 | string | ✅          | 微信支付订单号                                               |
| `logistics_type`                           | int    | ✅          | `1`=物流 `2`=无需物流 `3`=自提 `4`=同城配送                  |
| `delivery_mode`                            | int    | ✅          | **必须传**，统一发货填 `1`                                   |
| `shipping_list`                            | array  | ✅          | **即使无需物流也要传空数组 `[]`**，不能省略                  |
| `shipping_list[].tracking_no`              | string | 物流时必填 | 必须是快递公司能识别的真实单号                               |
| `shipping_list[].express_company`          | string | 物流时必填 | **必须是微信规定的编码**，如 `SF`、`ZTO`、`YTO`              |
| `shipping_list[].contact.receiver_contact` | string | 推荐       | 脱敏手机号，格式 `+86-138****8000`                           |
| `item_desc`                                | array  | ✅          | **必须是对象数组**，不能是字符串！每个对象含 `item_name`+ `item_count` |
| `delivery_time`                            | int    | ✅          | 发货时间，**Unix 时间戳（秒）**                              |
| `upload_time`                              | int    | ✅          | 上传时间，**Unix 时间戳（秒）**                              |
| `payer_openid`                             | string | ✅          | 付款人 openid                                                |

### 🔧 Step 1：在 `WeChatApiClient`里封装 Builder 方法

```
/**
 * 构建微信发货请求体（主流设计）
 */
public ObjectNode buildShippingRequestBody(
        String transactionId,
        int logisticsType,
        List<ShippingItem> shippingItems,
        List<ItemDesc> itemDescs,
        String payerOpenid) {

    ObjectNode body = createObjectNode();

    // 1. order_key
    ObjectNode orderKey = createObjectNode();
    orderKey.put("order_number_type", 2); // 2=微信支付单号
    orderKey.put("transaction_id", transactionId);
    body.set("order_key", orderKey);

    // 2. logistics_type
    body.put("logistics_type", logisticsType);

    // 3. delivery_mode（统一发货）
    body.put("delivery_mode", 1);

    // 4. shipping_list
    ArrayNode shippingList = createArrayNode();
    if (logisticsType == 1) {
        for (ShippingItem item : shippingItems) {
            ObjectNode shipping = createObjectNode();
            shipping.put("tracking_no", item.getTrackingNo());
            shipping.put("express_company", item.getExpressCompany());
            
            // 可选：收件人联系方式
            if (item.getReceiverContact() != null) {
                ObjectNode contact = createObjectNode();
                contact.put("receiver_contact", item.getReceiverContact());
                shipping.set("contact", contact);
            }
            shippingList.add(shipping);
        }
    }
    // logistics_type=2 时传空数组，不能省略
    body.set("shipping_list", shippingList);

    // 5. item_desc（必须是数组！）
    ArrayNode itemDescArray = createArrayNode();
    for (ItemDesc desc : itemDescs) {
        ObjectNode item = createObjectNode();
        item.put("item_name", desc.getItemName());
        item.put("item_count", desc.getItemCount());
        itemDescArray.add(item);
    }
    body.set("item_desc", itemDescArray);

    // 6. 时间戳（秒）
    long now = System.currentTimeMillis() / 1000;
    body.put("delivery_time", now);
    body.put("upload_time", now);

    // 7. 付款人 openid
    body.put("payer_openid", payerOpenid);

    return body;
}

// ============ DTO 内部类 ============

public static class ShippingItem {
    private String trackingNo;
    private String expressCompany;
    private String receiverContact; // 可选，如 "+86-138****8000"

    public ShippingItem(String trackingNo, String expressCompany) {
        this.trackingNo = trackingNo;
        this.expressCompany = expressCompany;
    }

    public ShippingItem(String trackingNo, String expressCompany, String receiverContact) {
        this.trackingNo = trackingNo;
        this.expressCompany = expressCompany;
        this.receiverContact = receiverContact;
    }

    // getters
    public String getTrackingNo() { return trackingNo; }
    public String getExpressCompany() { return expressCompany; }
    public String getReceiverContact() { return receiverContact; }
}

public static class ItemDesc {
    private String itemName;
    private int itemCount;

    public ItemDesc(String itemName, int itemCount) {
        this.itemName = itemName;
        this.itemCount = itemCount;
    }

    public String getItemName() { return itemName; }
    public int getItemCount() { return itemCount; }
}
```

### 🔧 Step 2：`OrderServiceImpl`里的调用方式

```
private void doUploadShipping(OmsOrder order, String clientId) {

    // 1. 获取 openid
    String openid = getOpenidByMemberId(order.getMemberId());

    // 2. 查询订单项
    List<OmsOrderItem> orderItems = orderItemService.list(
        Wrappers.<OmsOrderItem>lambdaQuery()
            .eq(OmsOrderItem::getOrderId, order.getId())
    );

    // 3. 构建 item_desc
    List<WeChatApiClient.ItemDesc> itemDescs = orderItems.stream()
        .map(item -> new WeChatApiClient.ItemDesc(
            item.getSpuName() + "【" + item.getSkuName() + "】",
            item.getQuantity()
        ))
        .collect(Collectors.toList());

    // 4. 判断发货方式（从订单/配置读取）
    Integer logisticsType = determineLogisticsType(order);

    List<WeChatApiClient.ShippingItem> shippingItems = new ArrayList<>();
    
    if (logisticsType == 1) {
        // 物流配送：从订单物流表读取真实单号
        OmsOrderDelivery delivery = orderDeliveryService.getByOrderId(order.getId());
        shippingItems.add(new WeChatApiClient.ShippingItem(
            delivery.getTrackingNo(),
            delivery.getExpressCompanyCode(), // 必须是微信编码，如 "SF"
            maskPhone(delivery.getReceiverPhone()) // 可选脱敏
        ));
    }
    // logisticsType=2 时 shippingItems 留空，builder 里会自动处理

    // 5. 构建请求体
    ObjectNode requestBody = weChatApiClient.buildShippingRequestBody(
        order.getOutTradeNo(), // 或者 transaction_id，取决于你存的是哪个
        logisticsType,
        shippingItems,
        itemDescs,
        openid
    );

    log.info("【微信发货】请求体: {}", requestBody);

    // 6. 调用
    JsonNode response = weChatApiClient.uploadShippingInfo(clientId, requestBody);
    log.info("【微信发货】微信返回: {}", response);
}
```

### 🔧 Step 3：物流类型判定策略（主流做法）

```
/**
 * 根据订单属性判定物流类型
 * 主流做法：订单表里加一个字段 logistics_type，或者根据商品类型判定
 */
private int determineLogisticsType(OmsOrder order) {
    // 方案A：从订单表字段读（推荐）
    if (order.getLogisticsType() != null) {
        return order.getLogisticsType();
    }
    
    // 方案B：根据商品是否有实物判定
    // 虚拟商品（卡券、会员等）→ 2
    // 实物商品 → 1
    boolean hasPhysicalProduct = checkHasPhysicalProduct(order.getId());
    return hasPhysicalProduct ? 1 : 2;
}

/**
 * 手机号脱敏（微信推荐格式）
 */
private String maskPhone(String phone) {
    if (phone == null || phone.length() < 11) {
        return phone;
    }
    return "+86-" + phone.substring(0, 3) + "****" + phone.substring(7);
}
```

## 五、你之前 412 的 99% 原因（总结）

对照主流设计，你之前的代码大概率踩了这几个坑之一：

| #    | 坑                      | 你的现状                                   | 修复                                      |
| ---- | ----------------------- | ------------------------------------------ | ----------------------------------------- |
| 1    | `item_desc`传了字符串   | 日志显示 `"华为冰箱【金色-12】 x1"`        | 改成对象数组                              |
| 2    | `shipping_list`没传     | 日志里没看到                               | 必须传（哪怕是空数组）                    |
| 3    | `delivery_mode`没传     | 日志里没看到                               | 加上 `body.put("delivery_mode", 1)`       |
| 4    | `tracking_no`直接放顶层 | 微信要求放在 `shipping_list[].tracking_no` | 移入嵌套结构                              |
| 5    | `tracking_no = "22222"` | 测试数据                                   | 要么用真实单号，要么改 `logistics_type=2` |
